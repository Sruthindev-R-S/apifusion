# Backend Server

This is the backend for the API Fusion project, built with Node.js and Express.

## Getting Started

Follow these instructions to get the backend server up and running on your local machine.

### Prerequisites

- [Node.js](https://nodejs.org/)

### Installation

1.  Navigate to the `backend` directory:
    ```sh
    cd backend
    ```
2.  Install the dependencies:
    ```sh
    npm install
    ```

### Environment Variables

Create a `.env` file in the `backend` directory and add the necessary environment variables. You can use `.env.example` as a template.

### Running the Server

To start the development server, run:
```sh
npm run dev
```
