# API Fusion Full Stack Project

This repository contains the source code for the API Fusion full stack application.

## Project Structure

- **/backend**: Contains the Node.js Express server. See the [backend README](./backend/README.md) for more details.
- **/frontend**: Contains the client-side application. See the [frontend README](./frontend/README.md) for more details.

## Getting Started

To get the full application running, you will need to set up both the backend and the frontend. Please refer to the README file in each directory for specific instructions.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18.x or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)# apifusion
